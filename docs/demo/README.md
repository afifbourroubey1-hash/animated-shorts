# النتيجة التجريبية

- `rail_gaps_preview.mp4`: الحلقة كاملة كما أنتجها خط الإنتاج **دون أي تعديل يدوي**:
  ريندر Cycles على معالج (4 أنوية، بلا كرت شاشة)، 360×640 بمعدل 15 إطاراً في الثانية، مكبّرة إلى 540×960 لتصغير الحجم.
- `contact_sheet.png`: إطار من منتصف كل لقطة (17 لقطة).

**الصوت في هذه المعاينة آلي (espeak-ng)** وهو مؤقت فقط، لأن رصيد ElevenLabs في الحساب المتصل
لم يكفِ (الحلقة تحتاج ≈ 1,118 حرفاً). لإنتاج النسخة الحقيقية:

```bash
export ELEVENLABS_API_KEY=...
make voice captions audio EP=rail_gaps          # صوت حقيقي + توقيت دقيق
make final video EP=rail_gaps BLENDER=blender   # 1080x1920 30fps على كرت الشاشة
```
